# CareerVault Content Standards

## General Principles

All content must be practical, truthful, and applicant-friendly. No fabricated statistics, guaranteed outcomes, or company-specific hiring claims.

## Resource Quality Requirements

### Resume Templates and Examples
- Use realistic fictional examples clearly labelled as examples
- Achievement-oriented writing with appropriate metrics
- Truthful descriptions of skills and experience
- ATS-friendly structure without misleading keyword stuffing
- Templates must be editable and customisable

### Interview Questions and Answers
- All questions must be original and professionally relevant
- Answer frameworks must be structured and actionable
- Example answers must use fictional candidates clearly labelled
- Evaluation rubrics must be consistent and fair
- No guaranteed interview success rates claimed
- Competencies assessed must be clearly identified

### Recruiter Messages
- Templates must be professional and respectful
- No guaranteed response rates claimed
- All placeholders must be clearly marked
- Tone should be appropriate for the context

### Salary and Offer Resources
- Clearly distinguish fixed compensation, variable compensation, bonuses, benefits, deductions and take-home salary
- All calculations must include explicit assumptions
- Never represent estimates as official payroll calculations
- Allow users to edit all assumption values

### AI Prompts
- Prompts must be tested and functional
- Required user inputs must be clearly specified
- Example inputs and expected output characteristics must be documented
- Limitations must be honestly stated
- Testing status must be tracked

### Roadmaps and Trackers
- Must include measurable tasks and clear milestones
- Timeframes must be realistic for working professionals
- Progress tracking must be practical and actionable

## Metadata Requirements

Every structured resource must include:
- Unique resource ID
- Title
- Module assignment
- Career track classification
- Relevant job roles
- Experience level
- Intended user description
- Description field
- Instructions where applicable
- Content body
- Examples where applicable
- Source references (for external claims)
- Creation date
- Last reviewed date
- Review status (draft, reviewed, approved)
- Version number

## Formatting Standards

- Consistent heading hierarchy
- Professional table formatting
- Clear whitespace and readability
- Consistent date formats
- Uniform resource ID schemas

## Prohibited Content

- Invented ATS scoring percentages
- Guaranteed recruiter visibility
- Invented salary increase percentages
- Invented interview success rates
- Company-specific hiring questions presented as universal
- Customer testimonials or results
- Fabricated statistics or outcomes
