## Executive Summary

The CareerVault website already has a strong premium visual foundation. The owner's feedback confirms the redesign direction is correct. This report focuses on **filling the gap between the excellent design and accurate, convincing product communication** — without fabricating statistics, inventing social proof, or making claims the product cannot support.

The central challenge: **Make ₹3,999 feel like a reasonable investment in a practical toolkit, not an arbitrary price attached to files.** The product is strong; the communication needs to be honest, specific, and deeply useful.

## 1. The Customer Journey — Six Stages

### Stage 1: Recognition (Homepage Hero)

**What the Indian professional is thinking:**
- "I'm tired of applying blindly."
- "My resume doesn't get responses."
- "I don't know how to negotiate salary."
- "Preparing for interviews is exhausting and unstructured."

**What the website must communicate within 5 seconds:**
- CareerVault is for working professionals (1–5 years experience) wanting a structured job switch.
- It provides 8 organised modules, not random online advice.
- You get lifetime access to templates, frameworks, and tools — nothing expires.

**Design Action:** Keep the existing hero visual. Update the headline from the current version to:
> "Your next career move deserves a better strategy."
> *(Preserved from current design — strong, professional)*

Add a subhead that specifies the problem:
> "8 modules, 200+ interview frameworks, 389 files — everything to prepare, search, interview & negotiate your next role."

### Stage 2: Interest (Problem Demonstration)

**The visitor needs to recognise their own situation.**

**Design:** Create a "Cost of an Unstructured Job Search" section using **actual, observable problems** — no invented statistics.

**Problems to list (all verifiable):**
- Applying without a structured strategy → relies on luck, not system
- Generic resumes for every application → lower response rates
- Incomplete professional profile → missed opportunities
- Interview prep without a repeatable system → inconsistent performance
- Salary negotiation without data → accepted first offer
- Losing track of applications and follow-ups → wasted effort
- Scams and unreliable online advice → time wasted

**How to connect to CareerVault:**
- Module 01 (Resume) → fixes generic resumes, provides 15 templates
- Module 03 (Job Search System) → fixes lost track, provides tracker + scam guide
- Module 04 (Interview) → fixes unstructured prep, provides 200+ questions + STAR workbook
- Module 05 (Salary Negotiation) → fixes accepted first offer, provides negotiation frameworks

**Key principle:** Customer recognition, not fear. The visitor should nod in recognition, not feel alarmed.

### Stage 3: Understanding (How Eight Modules Work Together)

**Design:** A simple visual journey showing the 8-step process.

**The 8-Step Journey (visually):**
1. **Prepare stronger professional profile** → Module 02
2. **Build optimised resume** → Module 01
3. **Organise job search** → Module 03
4. **Prepare for interviews** → Module 04
5. **Approach salary negotiation** → Module 05
6. **Use AI tools for career tasks** → Module 06
7. **Follow 90-day structured programme** → Module 07
8. **Plan career advancement** → Module 08

**Design Action:** Use the existing module grid on the product page, but add one-sentence descriptions for each module explaining its role in the journey. Preserve the visual design.

### Stage 4: Product Confidence (Demonstrate the Product)

**This is the most important stage. The visitor must understand what they are buying.**

**Design Action: "Inside CareerVault" experience using ACTUAL resources.**

**What to show (using real files):**

| Feature | How to Display |
|---------|---------------|
| **Resume templates** | Show 2-3 actual template previews (first page only) from the 15 .docx files |
| **Interview question library** | Show 2-3 actual questions from the 200+ commercial JSON questions |
| **STAR workbook** | Show a snippet from the .docx workbook |
| **Salary calculator** | Show the .xlsx calculator preview |
| **90-day dashboard** | Show the .xlsx dashboard preview |
| **AI prompt library** | Show 2-3 actual prompts from the .pdf library |

**Key rule:** Never display fabricated previews. Use actual resources from the product package. If a preview doesn't look professional, don't show it — instead, describe what the customer receives.

### Stage 5: Purchase Motivation (Make ₹3,999 Feel Reasonable)

**The customer must understand the value.**

**Pricing Section Design:**
- **Headline:** "One-time ₹3,999 — Lifetime access"
- **What's included:**
  - 8 modules with 389 files total
  - 15 resume templates + 8 role-specific guides
  - 200+ interview questions with answer frameworks
  - 6 career track–specific salary negotiation guides
  - AI prompt libraries for career development
  - 90-day job-switch programme with daily tracker
  - Lifetime access — no subscription, ever
  - GST invoice automatically generated
  - 7-day no-questions-asked refund policy

- **Comparison (honest):** 
  - "One payment of ₹3,999 vs. ₹2,000+/month on subscription platforms"
  - "One organised system vs. searching across 10+ websites for disconnected resources"
  - "Lifetime access vs. limited-time course access"

**Key principle:** The customer should feel this is a considered investment in a practical toolkit, not an arbitrary price.

### Stage 6: Checkout (Purchase Confidence)

**Design Action:** Review checkout from the customer's perspective.

**Clarity requirements:**
- Exact amount: "₹3,999 (inclusive of 18% GST)"
- One-time payment — no recurring charges
- GST invoice automatically generated upon payment
- Instant download access after successful payment
- 7-day refund policy if the product isn't what was expected
- What happens after purchase: email with library access link, all 389 files ready to download

**Do not add:**
- Fake countdown timers
- False limited-stock claims
- Artificially inflated crossed-out prices
- Hidden recurring charges
